# Сайт «Мама Маруся» — фуршеты и полуфабрикаты (Мозырь)

Статический сайт: только HTML, CSS, JavaScript, фото и шрифты. Никаких сборок и зависимостей.

## Структура

```
index.html      главная
menu.html       меню с корзиной
css/            стили (style.css) и подключение шрифтов (fonts.css)
js/data.js      ДАННЫЕ: блюда, цены, отзывы, FAQ — правится вручную
js/main.js      корзина, заказ в Telegram
js/menu.js      страница меню
js/home.js      главная (отзывы, FAQ)
photos/         фото блюд (используются в карточках меню)
assets/         иконки (icons.svg), фавиконка
fonts/          шрифт Manrope
.nojekyll       нужен для GitHub Pages
```

## Публикация на GitHub Pages

1. Зарегистрируйтесь на github.com (если аккаунта нет).
2. Нажмите **New repository** → имя, например `mama-marysya` → **Create** (Public).
3. На странице репозитория: **Add file → Upload files** → перетащите **содержимое этой папки**
   (index.html, menu.html, папки css, js, photos, assets, fonts, файл .nojekyll и README.md) → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → **Save**.
5. Через 1–3 минуты сайт будет доступен по адресу
   `https://ВАШ-ЛОГИН.github.io/mama-marysya/`

Чтобы обновить сайт после правок — просто загрузите изменённые файлы тем же способом (Add file → Upload files → перезаписать).

## Как обновлять данные (js/data.js)

Откройте `js/data.js` в любом редакторе (например, блокноте):

- **Цена блюда** — найдите блюдо по названию, поменяйте число у `"price"` (в рублях).
- **Название / состав / вес** — поля `"name"`, `"ingredients"`, `"weight"`.
- **Отзывы** — блок `"reviews"`. Сейчас там черновые тексты — замените на реальные
  (имя, повод, текст). Кавычки в тексте — только «ёлочки», прямые `"` ломают файл.
- **Вопросы-ответы** — блок `"faq"`.
- **Телефон / Telegram / Instagram** — блок `"config"` в начале файла.

После правок загрузите файл на GitHub — сайт обновится сам через минуту-две.

## Как добавить фото

**Фото блюда в меню:** положите файл в папку `photos/` и укажите его имя у блюда: `"image": "photos/imya-fayla.jpg"`.

**Фото на главной странице:** у карточек «Фуршеты и банкеты» и «Домашние полуфабрикаты» в `index.html`
прописан атрибут `data-photo="photos/имя-файла.jpg"` — поменяйте путь, и фото в карточке сменится.
Если путь стереть (`data-photo=""`), карточка вернётся к виду без фото.
Такой же атрибут можно добавить любому другому блоку на главной — фото появится сверху блока.

## Про кнопку «Заказать в Telegram»

Кнопка открывает чат `@Mari_Makarevich` и пытается подставить состав корзины в поле сообщения.
На телефонах (iOS/Android) текст подставляется автоматически; на некоторых компьютерных
клиентах Telegram этого не делает — для этого под кнопкой есть ссылка
«Текст не вставился?» с кнопкой копирования заказа.
